# Deva Alüminyum

Deva Alüminyum kurumsal web sitesi, arşiv kurtarma, SEO ve dijital varlık yeniden yapılandırma projesi.

## Kurtarma hedefi
- Eski `devaaluminyum.com` URL'lerini envanterlemek
- Wayback Machine'de bulunan HTML, görsel, PDF, CSS, JS ve diğer statik varlıkları kurtarmak
- Proje / referans / galeri sayfalarını ve görsellerini mümkün olduğunca toplamak
- Ham arşivi yeni site kodundan ayrı tutmak
- Yeni resmi alan adı `devaaluminyum.com.tr` için SEO/URL eşleme çalışmasını hazırlamak

## Güvenlik
Bu repo public'tir. API anahtarı, token, şifre, Search Console özel verisi veya başka gizli bilgi commitlenmez.
